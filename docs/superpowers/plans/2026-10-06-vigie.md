# La Vigie 🗼 remplace la Pompe — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.
> Plan à briefs : les règles, interfaces et cas de test sont exacts ; le code est écrit par l'implémenteur
> (changement transversal dans un moteur existant — lire le code autour avant d'éditer).

**Goal:** Remplacer l'archétype Pompe par la Vigie (un personnage monte sur une tour : garde, tir, portée) et le Capitaine Économie par le Capitaine Garnison, puis rééquilibrer par la simulation.

**Architecture:** La Vigie n'est pas une unité : c'est un état porté par la tour (`tower.vigie`). Le moteur calcule les dégâts/portée effectifs de la tour et absorbe les coups par la garde. La vue publique expose `buildings[].vigie`, le flux différentiel la transporte, le plateau la dessine.

**Tech Stack:** Node.js, moteur pur `src/game/engine.js`, rendu SVG `public/arena-board.js`, tests = scripts `node scripts/test-*.js`, simulation `node scripts/simulate-balance.js`.

**Spec:** `docs/superpowers/specs/2026-10-06-vigie-design.md`

## Review Focus

1. Tour détruite alors que sa Vigie est en poste → pose `destroyed`, carte perdue au règlement, plus de bonus.
2. Vigie posée alors que toutes les tours sont prises ou détruites (y compris une Vigie encore « en pose ») → refus `no_tower`, élixir non débité.
3. Garde : les dégâts vont d'abord à la garde, l'excédent passe à la tour ; le Rempart (invulnérabilité) bloque tout, garde comprise.
4. Ancienne donnée : surcharge `pompe`, Capitaine Pompe dans un deck enregistré → Vigie / Garnison sans plantage.
5. Vigie expirée → pose `expired` : même règle au règlement qu'une Pompe expirée aujourd'hui (lire `settle.js` et garder ce comportement, test à l'appui).

### Task 1: Moteur — Vigie, Garnison, retrait de la Pompe et d'Économie

**Files:** `src/game/cards.js`, `src/game/captains.js`, `src/game/engine.js`, `src/game/settle.js` (commentaire), `src/game/deck.js` (AUTO_PLAN), tests `scripts/test-arena-cards.js`, `test-arena-cardtype.js`, `test-arena-engine.js`, `test-arena-mechanics.js`, `test-arena-placement.js`, `test-arena-targeting.js`, `test-arena-deck.js`, `test-arena-settle.js` (tout test qui utilise `pompe`).

**Interfaces produites :**
- `ARCHETYPES.vigie = { key: 'vigie', label: 'Vigie', emoji: '🗼', share: 5, cost: 4, durationMs: 40000, guard: 250, dpsBonus: 0.6, rangeBonus: 4 }` (à la place exacte de `pompe`).
- `getCardStats` pour une Vigie → `{ ..., archetype: 'vigie', cost, durationMs: durationMs × mult, guard: guard × mult, dpsBonus, rangeBonus }` (mult = rareté, comme les PV).
- Surcharge `archetype: 'pompe'` → `'vigie'` (dans `getCardStats`/lecture des surcharges) ; `setArchetype(url, 'pompe')` refusé (type inconnu).
- `CAPTAINS.vigie = { style: 'Garnison', passive: 'Tes Vigies restent 50 % plus longtemps.', power: { key: 'alarme', label: 'Alarme', lane: false, desc: 'Toutes tes tours en vie tirent deux fois plus fort pendant 6 s.' } }` ; `CAPTAINS.pompe` supprimé.
- `TUNING` : retirer `startElixir`, `elixirMax`, `ecoRegen`, `surchauffeMs` ; ajouter `vigieDuration: 1.5`, `alarmeMs: 6000`, `alarmeDps: 2`.
- Tour : `tower.vigie = null | { poseId, url, until, guard, guardMax, dpsBonus, rangeBonus }`.
- `player.effects = { alarmUntil, rageUntil }` (plus d'`overheatUntil`).
- `publicState` : `players[s].alarm` (booléen) à la place de `overheat` ; `buildings[]` ajoute `vigie: null | { url, guard, guardMax, remainingMs }` (tours seulement).
- Raison de refus `no_tower` (remplace `pump_active`).
- Événements : `spawn` (archetype `vigie`, x/y de la tour), `vigie_end` `{ side, lane }` à l'expiration.

**Règles moteur :**
- Pose d'une Vigie (`deploy` avec `x/depth` ou `lane`) : point → tour vivante du camp, sans Vigie ni Vigie en attente, la plus proche (distance `D`) ; aucune → `{ ok: false, reason: 'no_tower' }` sans débit. Pas de contrôle de zone de pose. La pose en attente prend x/y de la tour (et garde la tour visée : `pending.towerId`).
- Apparition : si la tour visée est morte ou occupée entre-temps (0,5 s), la pose est marquée `expired` (carte sauvée, élixir perdu) avec un événement `vigie_end`. Sinon `tower.vigie = { …, until: now + durationMs × (Capitaine Garnison ? vigieDuration : 1) }`.
- Tir de tour : dégâts = `dps × (1 + vigie.dpsBonus si Vigie) × (alarmeDps si alarme active)` ; portée = `range + vigie.rangeBonus` (dans la recherche de cible de la tour aussi). Le QG n'est pas concerné par la Vigie ; l'Alarme concerne les **tours** seulement.
- Dégâts reçus par une tour avec Vigie : la garde absorbe d'abord, l'excédent touche la tour ; l'invulnérabilité (Rempart) passe avant tout.
- Expiration (`now >= until`) : `tower.vigie = null`, pose `expired`, événement `vigie_end`.
- Tour détruite avec Vigie : pose `destroyed`, `tower.vigie = null`.
- Pouvoir `alarme` : `effects.alarmUntil = now + alarmeMs`.
- Retirer tout le code Pompe (bâtiment `kind: 'pompe'`, production, `hasPump`, préférence de ciblage des Sorts/unités pour la Pompe, élixir de départ/max/regen Économie, Surchauffe).
- `endMatch` : une pose de Vigie en poste est `alive` (même règle que les troupes vivantes).

**Tests à écrire (dans `scripts/test-arena-mechanics.js`, section « 🗼 Vigie ») :**
- [ ] Pose sur la tour la plus proche du point ; refus `no_tower` quand les 3 tours sont occupées (dont une en attente) ; refus quand toutes sont détruites ; élixir non débité au refus.
- [ ] Tour avec Vigie : un ennemi à `range + 3` est visé (et pas sans Vigie) ; dégâts par seconde ×1,6 mesurés sur une cible.
- [ ] Garde : 100 dégâts → garde −100, tour intacte ; dégâts > garde → excédent sur la tour ; Rempart actif → rien.
- [ ] Expiration à 40 s (commune) → pose `expired` ; Capitaine Garnison → 60 s.
- [ ] Tour détruite avec Vigie → pose `destroyed` ; au règlement la carte est perdue (test dans `test-arena-settle.js`).
- [ ] Alarme : tours ×2 pendant 6 s, puis retour ; refus `power_used` la 2e fois.
- [ ] `publicState` : `buildings[].vigie` (url, garde, temps restant) et `players[s].alarm`.
- [ ] Surcharge `pompe` lue `vigie` ; carte qui tirait Pompe tire Vigie (même url → Vigie) ; Capitaine sur une ancienne Pompe → Garnison.
- [ ] Mettre à jour/supprimer tous les tests Pompe/Économie/Surchauffe existants.

- [ ] Lancer tous les `scripts/test-arena-*.js` + `test-tv-*.js` → verts. Commit `🗼 v2.3 : la Vigie remplace la Pompe (moteur) + Capitaine Garnison`.
